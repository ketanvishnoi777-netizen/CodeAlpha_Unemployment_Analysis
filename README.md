# Unemployment Analysis in India

## Task 2 - CodeAlpha Data Science Internship

### Overview
Analyzed unemployment rate data in India using Python to identify trends, COVID-19 impact, and seasonal patterns.

### Dataset
- Source: Unemployment in India dataset
- 768 records across 28 states
- Time period: 2019 - 2020

### What's Covered
- Data cleaning and exploration
- Unemployment trend over time
- COVID-19 impact analysis (Pre vs Post lockdown)
- State-wise unemployment comparison
- Rural vs Urban comparison
- Seasonal trends
- Policy insights

### Libraries Used
- Pandas, NumPy, Matplotlib, Seaborn
